# FINAL AUDIT REPORT

ÇalışBase · 20.09.2026 · Windows x64 / Chromium (Electron 43.7.0).

Объём: приложение Next.js, локальная IndexedDB, формы, задачи, таймер, иконка, импорт/экспорт, перевод, адаптивность, зависимости, веб- и desktop-сборки. Пользовательские данные в проверках заменялись только в изолированных тестовых профилях. Личное хранилище и установленная программа не изменялись.

**C1 — устаревший Next.js, исправлено.** `package.json` и `package-lock.json`: установленный 16.2.6 попадал под опубликованные критические уязвимости. Возможность эксплуатации именно этого приложения не подтверждена: у него нет собственных Server Actions, загрузки AVIF или Windows production-сервера. Обновлено до 16.3.5, React/React DOM — до 19.2.8. Источник: [августовский выпуск безопасности Next.js](https://nextjs.org/blog/august-2026-security-release) и сохранённый результат npm audit. Обе сборки проходят. Риск изменения: обновление фреймворка; проверены типы, маршруты и интерфейс собранного приложения.

## Осталось

Четыре Moderate-уведомления одной цепочки `drizzle-kit → @esbuild-kit/esm-loader → core-utils → esbuild` в devDependencies. В production-приложении миграции и этот dev-сервер не используются. Предложенное npm автоматическое исправление — несовместимый откат drizzle-kit; оно не применялось. Источник: [GHSA-67mh-4wv8-2f99](https://github.com/advisories/GHSA-67mh-4wv8-2f99).

Приложение локальное: учётных записей, входа, восстановления пароля, серверных ролей, admin API и общей пользовательской БД нет. Шаблонные файлы auth/D1 не подключены к действующим маршрутам. Поэтому эти области отмечены как неприменимые, а не «проверенные и безопасные». Один браузерный профиль разделяет одно пространство; отдельные профили/устройства имеют независимые записи.

Правило блокировки задач действует в приложении. Локальное время, DevTools и восстановление внешней копии не являются защищённым серверным журналом. Открытое приложение проверяет смену дня каждые 30 секунд, при возвращении в окно и перед каждой записью.

## Что требует ручной проверки

- Реальное обновление установленной копии на компьютере пользователя с сохранением его профиля; installer не запускался автоматически в личном профиле.
- Решение AVG/SmartScreen для нового неподписанного установщика. Успешная сборка не означает подтверждённый антивирусом вердикт.
- Safari, Firefox, реальные iOS/Android, screen reader и полный WCAG-аудит. Проверки Chromium и размеров окна не заменяют эти среды.
- Закрытие/перезапуск браузера при физическом сбое диска, исчерпании квоты и запрете sessionStorage. Автосохранение и конфликт проверены, все отказы операционной системы не эмулировались.
- Полевые LCP/CLS/INP, медленные реальные устройства и полный нагрузочный профиль большого хранилища. Пагинация ограничивает DOM, но не заменяет такие замеры.
- Первое открытие/перезагрузка веб-сайта без сети требует уже доступных ресурсов; офлайн-сценарий подтверждён для загруженного приложения. Desktop содержит ресурсы локально.

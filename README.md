# FocusBase

FocusBase — локальное личное пространство для учёбы: задачи, материалы, заметки, фокус-сессии, таблицы и план недели в одном интерфейсе.

## Что работает

- «Сегодня»: главная задача, режим Minimum / Normal / Deep Work, план, фактическое время, просроченные задачи с явным выбором действия.
- Задачи: статусы Inbox → To do → In progress → Done, приоритеты, направления, проекты, чек-лист, теги, сроки, повторение без дубликатов и Kanban.
- Фокус: свободный таймер, обратный отсчёт, Pomodoro, пауза, полноэкранный режим, отвлекающие мысли, итоги и следующий шаг. Время считается по timestamp и паузы не засчитываются.
- Библиотека: ручное сохранение ссылок, типы, коллекции, статусы, избранное, поиск и защита от повторной ссылки.
- Заметки: Markdown-поле с предпросмотром, шаблоны, связи и автосохранение.
- Мои таблицы: пользовательские столбцы, сортировка, фильтры, поиск, закрепление, шаблоны и CSV импорт / экспорт с предпросмотром.
- План недели: задачи по дням, drag-and-drop, задачи без даты, фиксированные события и редактируемый школьный распорядок.
- Архив, корзина с восстановлением, документированный JSON backup с проверкой связей, тёмная тема, офлайн-баннер и настройки часового пояса.

Записи хранятся в IndexedDB конкретного браузера и устройства. Для переноса используйте JSON экспорт. Аккаунтов и автоматической синхронизации между устройствами нет.

При создании и редактировании задачи поле «Длительность, минут» видно сразу под названием. Можно выбрать 15/25/45/60/90 минут или ввести целое число 1–1440. Быстрое создание тоже принимает произвольное время. Запуск из карточки использует сохранённую длительность; выбор задачи на экране «Фокус» подставляет её время, которое можно изменить для конкретной сессии.

## Активность задач

В разделе «Задачи» таблица показывает создание и завершение за выбранный день, календарную неделю (понедельник–воскресенье), месяц и всё время. Выбор даты меняет первые три периода. Все даты рассчитываются в часовом поясе пространства.

«Создано» использует `createdAt`, «Завершено» — `completedAt`. Эти числа независимы: сегодня можно закончить задачу, созданную вчера. Готовность — доля сейчас завершённых задач среди созданных за период; «Ещё в работе» — оставшиеся активные задачи из той же группы. Архив учитывается, корзина и примеры исключаются. Фильтры списка на отчёт не влияют.

Повторное открытие задачи сбрасывает дату завершения; новое завершение фиксирует новую дату. Редактирование уже завершённой задачи дату не меняет. Повторяющиеся задачи создают следующий экземпляр без даты завершения. У старых задач без `completedAt` дата не угадывается по `updatedAt`: такие завершения учитываются только в итоге за всё время и готовности созданных задач, с пояснением в таблице. JSON-копии сохраняют это поле.

## Разделение данных посетителей

Общей серверной базы пользовательских записей нет. Страницы используют клиентский `lib/focusbase/store.ts`: IndexedDB `focusbase`, хранилище `workspace`, ключ `personal`. Одинаковое имя базы не объединяет данные разных устройств или профилей браузера. Сервер Vercel раздаёт приложение; операции с задачами не отправляются на сервер. Вкладки одного профиля и адреса сайта разделяют пространство и синхронизируются через BroadcastChannel.

Это изоляция по устройству и профилю браузера, без идентификации человека. На общем компьютере каждому нужен отдельный профиль браузера. Очистка данных браузера удалит записи; используйте JSON-копии. Для доступа к одному аккаунту с разных устройств понадобятся аутентификация и серверная база с проверкой владельца каждой записи. Для текущего локального режима такая база не требуется, и посетители могут пользоваться сайтом независимо друг от друга.

## Запуск локально

Нужен Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Для production-проверки:

```bash
npm run typecheck
npm test
npm run build
npm run start
```

## GitHub → Vercel

Проект подготовлен как обычное Next.js приложение. Vercel автоматически определяет Next.js и запускает `next build`; подключённый репозиторий будет пересобираться после push и pull request. См. официальные инструкции [Vercel for GitHub](https://vercel.com/docs/git/vercel-for-github) и [deployment в Next.js](https://nextjs.org/docs/app/getting-started/deploying).

1. Создайте пустой репозиторий GitHub и добавьте этот проект:

   ```bash
   git init
   git add .
   git commit -m "Build FocusBase first version"
   git branch -M main
   git remote add origin https://github.com/<ваш-профиль>/<репозиторий>.git
   git push -u origin main
   ```

2. В Vercel выберите **Add New → Project → Import Git Repository**, подключите GitHub и выберите репозиторий.
3. Оставьте Framework Preset **Next.js**, Build Command `next build`, Output Directory пустым, Install Command `npm ci`. Нажмите **Deploy**.
4. После этого push в `main` создаёт новый production deploy, а pull request получает preview deploy.

В Vercel не нужны переменные окружения для этой локальной версии. Публичный URL не превращает IndexedDB в общую базу: у каждого браузера остаётся своё пространство.

## Питомец на рабочем столе Windows

Браузерная иконка работает внутри страницы. Чтобы она оставалась поверх других приложений после закрытия главного окна, используйте **FocusBase Desktop**. В настольной версии откройте **Настройки → Показывать поверх других окон**. По умолчанию этот режим выключен. Для полного выхода используйте меню значка FocusBase рядом с часами Windows. Автозапуск при включении компьютера не устанавливается.

ПКМ по иконке → **Убрать иконку** скрывает питомца и сохраняет выбор. Вернуть его можно в настройках: «Показывать поверх других окон» в Windows или «Показывать иконку быстрого доступа» на сайте. Задачи и таймер не удаляются. В Windows отдельная иконка не дублируется внутри главного окна.

Иконку можно перетаскивать за сам значок или за ручку над ним. Короткое нажатие открывает панель. Положение сохраняется между запусками; после смены монитора иконка возвращается в видимую область. В браузере перетаскивание также доступно и сохраняется отдельно.

В панели **Выбрать задачу** открывает очередь всех незавершённых задач. Выберите первую задачу и нажмите «Начать». Стрелки меняют порядок; «Пропустить» переносит выбранную задачу в конец очереди без запуска таймера. Во время работы «Следующая» сохраняет отработанное время и запускает следующую задачу; «Отложить» сохраняет время и останавливается. Эти действия не завершают и не удаляют задачи. Порядок сохраняется в рабочем пространстве и JSON-копиях.

Начиная с 1.0.6 Windows-сборка — обычный установщик NSIS для текущего пользователя. Программа работает из постоянной папки, а не из временной распаковки portable EXE. `appId`, имя приложения, адрес `focusbase://app` и профиль `%APPDATA%/FocusBase` сохранены: задачи прежней desktop-версии используются в том же профиле Windows. Удаление приложения не очищает пользовательские данные (`deleteAppDataOnUninstall: false`). Проверка `node desktop/node_modules/electron/cli.js desktop/main.cjs --smoke-test` использует изолированный тестовый профиль.

Перед переходом сохраните JSON-копию в настройках и полностью выйдите из старой версии через меню возле часов. Запустите установщик, затем используйте созданный ярлык FocusBase. Старый portable EXE больше не нужен для запуска установленной версии. Установщик не запускает приложение автоматически. Новые установщики обновляют программу; автоматическое скачивание обновлений пока не подключено.

Данные браузера и настольного приложения хранятся отдельно. Экспортируйте JSON в браузере и восстановите его в настольном приложении через настройки.

Сборка Windows x64 (из корня проекта):

```powershell
npm ci
npm ci --prefix desktop
npm run desktop:package
```

После успешной сборки установщик: `outputs/desktop/FocusBase-Setup-1.0.6.exe`. Настольная сборка содержит локальную копию приложения и работает без запущенного сервера. Обновления сайта на Vercel автоматически в неё не попадают: для них нужна новая сборка.

Статус проверки 18.09.2026: повторная сборка NSIS 1.0.6 успешно завершена после прежней блокировки AVG. Готовый установщик — 104 880 771 байт; файл полностью прочитан для расчёта SHA-256: `D9ED70D41AFB0748545294679462465E184C3CEB897D7FD2156608991504ADB6`. Журнал: `outputs/desktop/build-1.0.6-retry.log`. Проверка приложения и восстановления иконки в изолированном профиле прошла. Установка в пользовательский профиль автоматически не выполнялась; результат анализа лаборатории AVG отдельно не подтверждён.

## Экспорт и восстановление

Откройте **Настройки и данные → Экспорт всех данных**. JSON содержит задачи, связи, сессии, настройки, архив и корзину. Восстановление сначала показывает состав файла и заменяет пространство только после отдельного подтверждения. CSV импортирует отдельную новую таблицу и не перезаписывает существующие таблицы.

## Проверки

Таблица активности покрыта тестами в `tests/task-activity.test.mjs`: календарные границы, часовой пояс, повторное завершение, открытие задачи заново, повторения, архив, корзина и совместимость резервных копий. После `npm run desktop:build` команда `node desktop/node_modules/electron/cli.js scripts/check-task-activity.cjs` проверяет готовое приложение в двух изолированных профилях Chromium: создание и завершение через интерфейс, сохранение после перезагрузки, независимость посетителей, общие вкладки одного профиля, английский интерфейс и мобильную ширину. Нужны зависимости из `desktop`; реальные пользовательские данные не используются.

`npm test` запускает 31 проверку доменной логики и IndexedDB: timestamp-таймер и паузы, повторяющиеся задачи, связи и резервные копии, CSV, небезопасные URL, часовой пояс, конкурентный запуск сессий, транзакции и восстановление. Основной сценарий дополнительно проверен в браузере: задача → ссылка → фокус → пауза после обновления → результат 11/13 → фактическое время → поиск заметки → корзина → восстановление → таблица и CSV.

Перед публичным продуктом нужны серверное хранилище с изоляцией пользователей, аутентификация, миграции, правила приватности, мониторинг, удаление аккаунта и проверка реальных мобильных устройств. Текущая версия не отправляет личные записи на сервер и не обещает облачную синхронизацию.
